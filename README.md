# 🎓 Campus Resource Hub

A modern, full-stack academic resource sharing platform built to help students discover, upload, and organize campus study materials, notes, and links in one centralized portal.

## ✨ Features

- **🔐 User Authentication:** Secure email/password login powered by Supabase Auth.
- **📚 Centralized Hub:** Browse, search, and filter academic materials across subjects.
- **📤 Resource Submissions:** Seamlessly submit learning materials or links.
- **🎨 Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **⚡ Real-time Data:** Instant fetching and live updates powered by PostgreSQL.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Database:** [Supabase](https://supabase.com/)
- **Hosting:** [Vercel](https://vercel.com/)

---

## 🗄️ Database Setup

The database schema and tables are managed via Supabase PostgreSQL. You can review the raw structure in `supabase/schema.sql`.
